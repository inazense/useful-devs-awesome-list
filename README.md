# Useful Devs Awesome List

Una lista curada de recursos web, herramientas útiles para el día a día y enlaces curiosos para desarrolladores, diseñadores y personas curiosas.

El repositorio está organizado en ficheros individuales por categoría. Haz clic en cualquiera de las secciones para explorar sus herramientas, consultar la descripción y acceder directamente a cada enlace en una nueva pestaña.

## 💡 Cómo navegar

- Cada categoría se encuentra en un archivo independiente dentro de la carpeta `categories/`.
- Todos los recursos cuentan con su URL, descripción en español y un botón con enlace externo que se abre en una pestaña nueva.
- Al final y al inicio de cada archivo dispones del enlace **[← Volver al menú principal](../README.md)** para volver cómodamente al índice.
